# Three-minute demonstration

Use the painted reference interior. Say, on screen, that it is a drawing with local model output, unless a live Meta badge is actually showing.

## 0:00–0:25 — The problem

Show the flat photograph.

“Photographs preserve what the camera saw. They hide the larger spatial experience. Generative systems can invent the missing world, and they do not always tell you what they invented.”

## 0:25–1:05 — The resurrection

Open the memory. Point at the processing trace: classical segmentation, Depth Anything V2, no generated pixels.

Drag the view a little. The photograph parallaxes inside a limited cone. Set depth to zero and the original picture returns.

If a key is configured, import a new photo with consent and point only at calls whose trace says live Meta.

## 1:05–1:45 — The epistemic moment

Switch the Truth Lens: Original, Observed, Inferred (blue depth), Generated (empty until a hypothesis exists), Testimony.

Click the record player. Read the lineage: pixels from the photograph, label from the Hough rule or from SAM if a live mask replaced it, relative depth, not calibrated.

## 1:45–2:25 — The spatial agent

Ask: “Show me the old record player.”

The tool trace lists `focus_camera_on_entity`. The camera moves. The narration quotes the label source and refuses a metric distance.

Ask: “What is behind this cupboard?”

The answer says the dark region was photographed and its contents are unknown.

## 2:25–2:45 — Memory branching

Ask: “My grandmother remembers a piano being next to the window.”

The testimony is stored as unresolved. Sketch the hypothesis. Switch between Original evidence and Piano hypothesis. The sketch is marked hypothetical and does not replace the photograph.

## 2:45–3:00 — The vision

“ChronoSpace doesn’t simply generate a world from your photograph. It preserves the evidence, exposes the uncertainty, and lets you explore the memory without confusing imagination with reality.”
